# 园区分区供水与夜间漏损核验数据定义

输入行数=有效行+隔离行+空行。供水量=售水量+授权用水+各区残差。value为原值，unit支持m3与L，value_m3为立方米。error_pct在0至10之间，误差按每条计量绝对值相加；不假设独立随机误差。时间必须含偏移，先转UTC；夜间为中国标准时间[00:00,05:00)。

以计量边为唯一事实归属分区，跨区转供在两侧分别记入并在全园合计相消；使用误差上下界判断漏损。

原始行号对应 CSV 解析器的物理末行。UTF-8 BOM 与 GB18030 均支持，坏行进入隔离区，结构性错误返回422。空文件、仅表头和全空记录分别返回不同原因码。金额与用量使用 Decimal，对外以字符串返回。编码和编号按字符串保留。

run_id 由输入摘要、参数和规则版本生成；revision 为人工复核版本。证据 CSV 含运行号、来源行、原因码、原始字段及最终结论。
